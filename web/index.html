One orbit, many nearby pixels

The Mandelbrot recurrence starts at zero. Each pixel supplies a complex parameter c:

z0 = 0   ·   zn+1 = zn2 + c

Instead of replaying every orbit from zero, Rust stores a cubic approximation to an already-computed orbit over a small patch. Local screen coordinates are u, and r is the patch scale:

c(u) = c0 + ru
zn(u) ≈ A + Bu + Cu² + Du³

Squaring the polynomial updates its four coefficients. With primed letters denoting the next iteration:

A′ = A² + c0
B′ = 2AB + r
C′ = 2AC + B²
D′ = 2AD + 2BC

Zooming translates and rescales this same polynomial, Q(s + fu). That change is exact for the stored cubic; discarding terms of degree four and above is the approximation.

How much error?

For neighboring parameters separated by δ, the orbit difference obeys an exact recurrence:

Δn+1 = 2znΔn + Δn² + δ

Small errors can grow roughly by a factor of 2|z| per step. There is no universal “one more zoom, one more iteration” rule. The renderer limits orbit spread and estimates newly discarded tails before skipping ahead. These checks do not certify accumulated error or exact membership of the set.

Where the speed comes from

  • At most eight shared orbit steps per frame, plus up to 24 more per tile on a fixed 16 × 12 grid.
  • 101 pixel continuation steps initially, adding five per 3× local zoom, capped at 201. Escaping or nearly repeating orbits stop early.
  • Cubic values advance across scanlines with additions. Two orbits run together using WASM SIMD; a scalar build supports browsers without it.
  • Analytic checks skip the main cardioid and period-two bulb. A palette table and approximate color logarithms avoid expensive repeated color math.
  • The periodic map caches sine values by row and column. Once deep detail fully covers the old orbit image, that hidden image is no longer rendered.
  • A worker renders one frame at a time and reuses buffers. Auto detail adjusts pixel count to the device; the display requests at most 30 frames per second.

What “forever” means here

The old renderer jumped to another atlas region after 12 decades. Automatic region changes are now removed. Between 108 and 1016 local zoom, the orbit image gradually gives way to a periodic, synthesized Mandelbrot-like field.

Two overlapping scales reveal detail continuously. At each scale boundary, the outgoing fine layer is the incoming coarse layer, so there is no image swap. Coordinates wrap periodically to keep numbers small. This is repeating artistic detail, not infinitely precise coordinates or guaranteed unique geometry. Zooming far back out can take a different path because old phase information is discarded.

The procedural layers also use the Mandelbrot recurrence, with a smooth periodic parameter map:

c(x, y) = −0.5 + 1.4 sin(x) + i · 1.1 sin(y)

Only Find another edge deliberately blends to a different region. Work and storage stay bounded at a fixed resolution; actual frame time varies with how quickly the visible orbits escape.

Everything runs on your device. No remote rendering or external math library. Desktop and emulated touch checks are automated; a physical iPhone has not been benchmarked.
